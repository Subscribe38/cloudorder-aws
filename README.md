# CloudOrder

CloudOrder is a cloud-based order management system designed to demonstrate the design, development and deployment of a production-ready application on AWS.

## Project Goals

- Build a functional web application
- Containerize the application using Docker
- Deploy the application on AWS
- Implement secure and highly available architecture
- Automate infrastructure using Terraform
- Implement CI/CD
- Implement monitoring and logging

## Planned AWS Architecture

The application will eventually use AWS services including:

- Amazon VPC
- Amazon ECS Fargate
- Amazon ECR
- Application Load Balancer
- Amazon RDS
- Amazon S3
- AWS IAM
- AWS Secrets Manager
- AWS KMS
- Amazon CloudWatch
- AWS WAF
